# Support

Use GitHub issues for reproducible bugs, documentation problems, compatibility
questions, and feature proposals.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.

When asking for help, include:

- The version of `@zimme/bunny-ddns-edge-script`.
- The Bunny Edge Script deployment path you are using.
- The DDNS client and version, for example inadyn.
- Sanitized configuration values.
- The exact DDNS response body returned by the script.
