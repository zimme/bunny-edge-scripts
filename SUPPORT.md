# Support

Use GitHub issues for reproducible bugs, documentation problems, compatibility
questions, and feature proposals.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.

When asking for help, include:

- The package and version. Before the first release, say `source at <commit>`
  instead of implying that `0.0.0` is a published package.
- The Bunny Edge Script deployment path you are using.
- The DDNS client and version, for example inadyn.
- Sanitized non-secret configuration, including hostname and zone scope.
- The exact response body returned by the script.

Never include Bunny API keys, DDNS shared secrets, Basic Auth headers, deploy
keys, or logs that contain credentials and have not been redacted.
